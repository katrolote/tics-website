# Video del circuito

Coloca aquí la demostración en video del circuito con el nombre exacto:

```
circuito-demo.mp4
```

Se reproducirá automáticamente en la sección **Circuito** de `index.html`
(`assets/video/circuito-demo.mp4`), con `assets/img/tinkercad-captura.svg`
como imagen de portada (`poster`) mientras no le den play.

## Qué grabar

Una demostración corta (uno o dos minutos) mostrando el circuito funcionando:

- En Tinkercad: la simulación corriendo, mostrando cómo reacciona a las
  entradas de los sensores (usa la grabación de pantalla de Tinkercad o
  cualquier grabador de pantalla).
- Si hicieron el **Reto de Suficiencia** (conexión física con el kit de
  robótica): graben el circuito real funcionando en vez de la simulación.

## Formato

MP4 (códec H.264) es el más compatible con navegadores y GitHub Pages.
Si tu grabación queda en otro formato (.mov, .webm), conviértela a `.mp4`
antes de subirla — la etiqueta `<video>` del sitio solo referencia esa
extensión.

# Documento Formal de Investigación

Coloca aquí el informe de la consultoría en ambos formatos:

- `investigacion.docx`
- `investigacion.pdf`

Luego, en `index.html` (sección `#investigacion`), actualiza los enlaces:

- `#githubLink` → enlace a este repositorio/carpeta en GitHub (para consultar los recursos).
- `#pdfLink` → enlace directo a `docs/investigacion.pdf`.

## Recordatorio de la guía (para no perder puntos)

- Hojas de colchón entre secciones principales.
- Saltos de **sección** (no saltos de página).
- Al menos una página en orientación horizontal para tablas/diagramas/esquemas de circuito.
- Encabezados y pies de página reales, configurados por sección, con numeración.
- Mínimo 5 temas principales / 18 subtemas relacionados con los fundamentos del proyecto y el IRTRA Petapa.
- Citas en todo párrafo que no sea de autoría propia + hoja de Referencias en Normas APA generada
  con la herramienta **nativa** de Word (no citadores externos ni páginas web).
